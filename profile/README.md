# Secori

Security research on open-source and AI software. We find weaknesses, verify them,
report them privately to the people who can fix them, and write up what is fixed.

- Findings and fixes: [disclosures](https://github.com/SecoriSecurity/disclosures)
- Website: [secori.io](https://secori.io)
- Report a problem in our software: see the [security policy](https://github.com/SecoriSecurity/.github/blob/main/SECURITY.md)

We are a research effort, not a security-services company.
